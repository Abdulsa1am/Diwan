# ديوان الشريف الرضي

موقع لقراءة ديوان الشريف الرضي كاملًا: ٦٨٥ قصيدة، مع البحث والفهارس والمعجم والأطلس.
هذه إعادة بناء للموقع السابق بالهوية نفسها، لكن أخف وأسرع، وصفحاته تظهر في محركات البحث.

## التشغيل على جهازك

تحتاج إلى [Node.js](https://nodejs.org) الإصدار ٢٢ أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر (عادةً `http://localhost:4321`).

## النشر على Cloudflare Pages

- أمر البناء: `npm run build`
- مجلد الناتج: `dist`

ملف `public/_redirects` يحوّل روابط الموقع القديم (مثل `/poem/r1-227/verse/3`) إلى أماكنها الجديدة.

## أين البيانات؟

- `data/source/`: بيانات الموقع القديم كما هي، دون أي تعديل.
- `data/edition/`: النسخة التي يعرضها الموقع. الفرق الوحيد: واو العطف متصلة بما بعدها («وإنّما» لا «و إنّما»). كل تعديل مسجّل في `reports/waw-changes.csv`.

## قبل نشر أي تعديل

```bash
npm run build
npm run verify
```

يتأكد `verify` من أن نص كل بيت ظاهر في صفحته كما هو، وأن لا رابط مكسور، وأن لا بريد شخصي في الموقع.

للتفاصيل التقنية والقرارات: `AGENTS.md`. لسير العمل: `PROGRESS.md`.
