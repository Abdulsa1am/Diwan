# ديوان الشريف الرضي

موقع لقراءة ديوان الشريف الرضي (٣٥٩–٤٠٦ هـ) كاملًا، والبحث فيه، وتصفّحه من مداخل كثيرة: البحور والقوافي والمطالع والأغراض والأعلام والمواضع والألفاظ.

**رابط النسخة التجريبية:** https://diwan-alradi-ce6.pages.dev

هذه نسخة تجريبية لأخذ آراء الأصدقاء، فيها مختبر الخطوط، ومحجوبة عن محركات البحث (`noindex`).

هذا الموقع إعادة بناء لموقع سابق صنعه صديقنا، بالهوية نفسها (الألوان والخطوط والشعار وتوزيع الصفحة)، لكن بطريقة بناء مختلفة: كل صفحة جاهزة سلفًا، فتفتح بسرعة على الجوال، ويقرأ محرّك البحث أبياتها.

### صفحة القصيدة
- **كل شطر في سطر واحد،** وأبيات القصيدة كلها بحجم واحد: يقيس الموقع أطول شطر ويختار الحجم على قدره. الشطران متجاوران على الشاشات العريضة، ومتتابعان على الجوال.
- **الشروح عند الطلب:** زر «الشروح» يُظهر شروح الأبيات ومعاني ألفاظها، و«شرح البيت» من قائمة رقم البيت يُظهر شرح بيت واحد. ١٬٧٦٤ حاشية مربوطة ببيتها بعد مقابلتها بصفحات الطبعة.
- **أدوات البيت** (اضغط رقم البيت): نسخ البيت، ونسخه مع الإحالة، ونسخ رابطه، ومشاركته.
- **أدوات القصيدة:** الحفظ في «محفوظاتي»، والنسخ، والمشاركة، و«صفة القراءة» (حجم الخط وترتيب الشطرين).
- **شريط القراءة:** يظهر فيه اسم القصيدة ورقم البيت ومؤشر التقدّم، ويختفي الشريطان العلوي والسفلي أثناء القراءة على الجوال.

### البحث
لا يضر اختلاف التشكيل ولا صور الهمزة: «إنما» تجد «وإنّما»، و«معقودة» تجد «معقوده». يمكن البحث بكل الألفاظ أو بالعبارة كما هي، وتقييده بالبحر والقافية والجزء، ورابط صفحة البحث يحفظ البحث نفسه فيمكن مشاركته.

### الوضع الليلي
زر القمر في الشريط العلوي، ويتذكر الموقع اختيارك.

## نص الديوان

- **المصدر:** نسخة رقمية لديوان الشريف الرضي (فريق مساحة حرة)، تطابق في المواضع المقابلة طبعة **يوسف شكري فرحات، دار الجيل — بيروت**. الجزء والصفحة مذكوران في كل قصيدة.
- **ما عُدّل في النص، وكله مسافات فقط لا حروف:**
  - واو العطف المنفصلة وُصلت: «و إنّما» ← «وإنّما»، كما في الطبعات المحققة.
  - ٣٦١ إصلاحًا مؤكدًا من مراجعة النص: همزة الاستفهام المنفصلة («أ ما» ← «أما»)، ومسافة بعد علامة التعجب والاستفهام («للّه!أيّ» ← «للّه! أيّ»)، وحذف المسافة قبل علامة الترقيم.
  - كل تعديل مسجّل: `reports/waw-changes.csv` و`reports/text-issues.csv`.
- **ما بقي كما طُبع:** الفواصل (نحو نصف الأبيات تنتهي صدورها بفاصلة)، وكل ما يحتاج الرجوع إلى الكتاب المطبوع. قائمة ما يحتاج مراجعة في `reports/text-issues.md`.
- **الحواشي والتراجم والأطلس والمعجم والأغراض** من عمل صاحب الموقع السابق ومراجعاته، نُقلت كما هي.

## مختبر الخطوط (مؤقت)

في هذه النسخة أداة تجريبية لاختيار الخطوط قبل اعتمادها: «مختبر الخطوط» في القائمة الجانبية، أو زر **T** في الشريط العلوي على الجوال.

- اختر خط الأبيات (٨ خطوط)، وخط العناوين (٩)، وخط الواجهة (٨)؛ يتغير الموقع كله فورًا، ويبقى اختيارك وأنت تتنقل بين الصفحات.
- «انسخ الاختيار» ينسخ أسماء الخطوط لترسلها، و«إعادة الخطوط الأصلية» يرجع كل شيء.
- الخطوط تُحمَّل من Google Fonts عند اختيارها فقط.

بعد اختيار الخطوط تُركَّب على الموقع نفسه ويُحذف المختبر (الخطوات في `PROGRESS.md`).

## للمطوّرين

### التشغيل على جهازك
تحتاج إلى [Node.js](https://nodejs.org) الإصدار ٢٢ أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر (عادةً `http://localhost:4321`).

### الأوامر

| الأمر | ماذا يفعل |
|---|---|
| `npm run dev` | تشغيل الموقع للتطوير |
| `npm run build` | بناء الموقع في مجلد `dist` |
| `npm run preview` | معاينة النسخة المبنية |
| `npm run verify` | فحص النسخة المبنية: نص كل بيت في صفحته كما هو، ولا رابط مكسور، وعنوان رئيسي واحد في كل صفحة، وعناوين غير مكررة، ولا بريد شخصي |
| `npm run check` | فحص أنواع الكود |
| `npm test` | اختبار قواعد البحث العربي |
| `npm run data` | إعادة بناء البيانات من الموقع السابق (يحتاج مجلد `_original`، وليس في المستودع) |

**قبل نشر أي تعديل:** `npm run build` ثم `npm run verify`.

### النشر على Cloudflare Pages
الموقع منشور في مشروع Cloudflare Pages اسمه `diwan-alradi`، وعنوانه `https://diwan-alradi-ce6.pages.dev`.

لنشر تحديث (من PowerShell، بعد تسجيل الدخول إلى Cloudflare بـ `npx wrangler login`):

```powershell
$env:SITE_URL = 'https://diwan-alradi-ce6.pages.dev'
$env:NOINDEX = '1'   # احذف هذا السطر عند النشر النهائي ليظهر الموقع في محركات البحث
npm run build
npm run verify
npx wrangler pages deploy dist --project-name=diwan-alradi --branch=main
```

- `SITE_URL`: عنوان الموقع، تُبنى عليه الروابط الأصلية وخريطة الموقع.
- `NOINDEX=1`: يضيف إلى كل صفحة وسمًا يطلب من محركات البحث تجاهلها (للنسخ التجريبية).
- `public/_redirects` يحوّل روابط الموقع السابق، مثل `/poem/r1-227/verse/3`، إلى أماكنها.

### بنية المشروع

| المجلد | ما فيه |
|---|---|
| `data/source/` | بيانات الموقع السابق كما استُخرجت، دون أي تعديل |
| `data/edition/` | النسخة التي يعرضها الموقع (بعد الإصلاحات المذكورة). لا تُعدَّل يدويًا: `npm run data` يعيد بناءها |
| `src/pages/` | صفحات الموقع، ملف لكل رابط |
| `src/lib/` | تجهيز البيانات وقت البناء (القصائد، الفهارس، المعجم، الأطلس، أقسام القائمة) |
| `src/scripts/` | الكود الذي يعمل في المتصفح (صفحة القصيدة، البحث، الأدوات) |
| `src/styles/global.css` | ألوان الهوية وتصميم الإطار العام |
| `tools/` | سكربتات البيانات والفحص |
| `reports/` | سجلات التعديلات وتقارير المراجعة |
